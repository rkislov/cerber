# Cerber

Cerber — проект платформы мониторинга безопасности и управления уязвимостями сети. Первый этап — сканер уязвимостей операционных систем с локальным и сетевым режимами работы.

Автор: **Кислов Роман Сергеевич**.

## Статус

Начальный этап разработки. Реализация сканера и SIEM пока отсутствует.

В перспективе платформа объединит инвентаризацию активов, управление устранением уязвимостей, сбор и поиск событий безопасности, корреляцию и работу с инцидентами.

## Возможности первого этапа

- Реестр активов, цели, задачи и расписания сканирования.
- Сетевые проверки и аутентифицированный сбор данных Windows/Linux.
- Интеграция с БДУ ФСТЭК и NIST NVD, включая офлайн-обновления.
- Русскоязычный интерфейс и экспорт отчётов.

Планируемый стек: Rust, Tauri 2, React и Tailwind CSS.
Целевые платформы: Windows x86_64; Linux x86_64 и aarch64.
