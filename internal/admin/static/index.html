Инвентарь

Зарегистрируйте новый узел или укажите ID уже существующего актива. Файл доступа будет доступен для скачивания один раз.

Передайте файл агенту по защищённому каналу. Установку и настройку службы выполните на узле.

ЗАДАНИЕ АГЕНТУ

Новый запуск

Windows: поиск в настроенной службе Windows Update / WSUS. Linux: кандидаты APT/RPM из кеша, либо с обновлением метаданных по выбранной опции. Пакеты и исправления не устанавливаются. Обновление метаданных требует прав службы.

При включении приостановленного расписания первый запуск ставится сразу. Изменение или отключение расписания не меняет уже поставленные задания.
