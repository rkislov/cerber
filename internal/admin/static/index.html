ЗАДАНИЕ АГЕНТУ

Новый запуск

Windows: поиск в настроенной службе Windows Update / WSUS. Linux: кандидаты APT/RPM из кеша, либо с обновлением метаданных по выбранной опции. Пакеты и исправления не устанавливаются. Обновление метаданных требует прав службы.

При включении приостановленного расписания первый запуск ставится сразу. Изменение или отключение расписания не меняет уже поставленные задания.

Windows использует настроенную службу WUA/WSUS. Linux по умолчанию читает кеш APT/RPM. Обновление метаданных требует прав службы; пакеты не устанавливаются.

При включении расписания первый запуск ставится сразу. Изменения затрагивают только будущие запуски.

ХРАНЕНИЕ СОБЫТИЙ
Сроки хранения и архивы
События переносятся только после обработки. Доказательства всех срабатываний остаются в оперативном журнале. Новые сроки действуют и для уже сохранённых данных. Истёкшие архивы удаляются без возможности восстановления средствами Cerber.
Одна партия — до 250 событий. Фоновое обслуживание выполняется каждую минуту. Файлы JSONL.gz проверяются по SHA-256 перед переносом и при скачивании. Свободные страницы SQLite используются повторно; размер файла БД автоматически не уменьшается.
